# Estudos de Algoritmos

Repositório criado para exercitar estudos de algoritmos e estruturas de dados.

## Sobre
Registro de implementações práticas, resoluções de problemas e anotações. O foco principal é a conversão da teoria em código, com atenção ao tempo de execução e gerenciamento de memória para grandes volumes de dados.

## Conteúdo
- Algoritmos em Grafos (ex: Algoritmo de Kosaraju para Strongly Connected Components).
- Implementações em Python (lidando com limites de recursão e threads).
- Ordenação, buscas e divisão e conquista.
